# Humanoid Animation Imports

Place animation FBX files here after checking the exact included clips and license. The Quaternius Universal Animation Library is a CC0 candidate for general locomotion and emotes. Do not assume it includes a football penalty kick or goalkeeper save/dive clip; inspect the archive and source or create/license those specific clips separately.

For animation-only FBX files, use the Unity Rig importer to copy the Avatar from the matching base character when necessary. Set clips to in-place playback because gameplay owns player and goalkeeper root movement.
